# ถ้ำเทียนดับ (Candle Cave)

> เกมสมมุติที่ใช้อธิบาย concept ทั่วทั้ง wiki
> ไฟล์นี้**ตั้งใจเขียนเป็นภาพรวมระดับ concept เท่านั้น ไม่ใช่กติกาที่เล่นได้ครบ** ช่องว่างที่เหลือไว้คือพื้นที่ของเกมที่คุณจะออกแบบเอง

| | |
|---|---|
| ผู้เล่น | 1 คน (solo) |
| อุปกรณ์ | ลูกเต๋า 2 ลูก (2d6), กระดาษ, ดินสอ |
| เวลา | ประมาณ 15 นาที |

## เป้าหมาย

ลงไปในถ้ำให้ลึกที่สุด แล้ว**กลับออกมาพร้อมสมบัติให้ได้มากที่สุด** ถ้าเทียนดับขณะยังอยู่ในถ้ำ ถือว่าแพ้และสมบัติหายหมด

เป้าหมายนี้ไม่ใช่แค่ "รอดออกมา" เพราะถ้าเป็นแบบนั้น วิธีที่ดีที่สุดคือไม่เข้าถ้ำเลย ดู [[player-goal]]

## ทรัพยากร: เทียน 10 ขีด

- วาดแถบ 10 ช่องบนกระดาษ ทุกครั้งที่เข้าห้องใหม่ให้ลบ 1 ขีด
- การเดินกลับผ่านห้องที่สำรวจไปแล้วก็เสียเทียนเหมือนกัน
- เหตุการณ์บางอย่าง เช่น หนีจากมอนสเตอร์ หรือโดนลมพัด ทำให้เสียเทียนเพิ่ม **ผู้เล่นจึงคำนวณทางกลับล่วงหน้าได้ไม่แน่นอน**

เทียนจึงเป็นทั้งนาฬิกา แสงสว่าง และเงื่อนไขแพ้ในเวลาเดียวกัน

## Core loop

```
เข้าห้องใหม่ (−1 เทียน)
   → ทอย 2d6 เปิดตารางห้อง
   → เจอ มอนสเตอร์ / กับดัก / สมบัติ / ห้องว่าง
   → เลือก สู้ / ย่อง / หนี   (แต่ละทางเสียทรัพยากรต่างกัน)
   → ตัดสินใจ: ลงลึกต่อ หรือ หันหลังกลับ
   ↺
```

## ตารางห้อง (ตัวอย่างบางส่วน ยังไม่ได้ balance)

| 2d6 | ห้อง | โอกาส |
|---|---|---|
| 2 | กับดักร้ายแรง | 1/36 ≈ 3% |
| 3–5 | มอนสเตอร์ | 9/36 = 25% |
| 6–8 | ห้องว่าง / ทางแยก | 16/36 ≈ 44% |
| 9–11 | สมบัติ | 9/36 = 25% |
| 12 | สมบัติหายาก | 1/36 ≈ 3% |

ผลรวมของลูกเต๋า 2 ลูกไม่ได้ออกทุกค่าเท่ากัน 7 ออกบ่อยที่สุด ส่วน 2 กับ 12 ออกยากที่สุด นักออกแบบใช้คุณสมบัตินี้กำหนดได้ว่าอะไรควรเจอบ่อย อะไรควรหายาก ดู [[probability]]

## หัวใจความสนุก

ช่วงที่น่าสนใจที่สุดของเกมคือ**ตอนยืนอยู่หน้าประตูห้องถัดไป** เทียนเหลือ 4 ขีด ถุงมีสมบัติ 2 ชิ้น จะเสี่ยงลงต่ออีกห้องไหม ถ้า playtest แล้วผู้เล่นไม่เคยลังเลตรงนี้เลย แปลว่าเกมนี้ยังไม่ทำงาน
