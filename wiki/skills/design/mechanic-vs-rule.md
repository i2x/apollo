# Mechanic vs Rule (กลไก กติกา และชิ้นส่วน)

## คืออะไร
เกมกระดาษประกอบด้วยสามชั้น ในวงการใช้คำพวกนี้ไม่ตรงกันเสมอไป wiki นี้จึงกำหนดความหมายไว้ดังนี้ **Component** คือของที่จับต้องได้ เช่น ลูกเต๋า การ์ด กระดาษ token **Rule** คือประโยคเดียวที่บอกว่าทำอะไรได้ ห้ามทำอะไร หรือจะเกิดอะไรขึ้น **Mechanic** คือกลุ่มของ rule ที่ทำงานร่วมกันจนเป็นระบบที่ผู้เล่นโต้ตอบด้วย และมักมีชื่อที่ใช้เรียกข้ามเกมได้ เช่น push-your-luck, dice pool, deck building เหตุผลที่ต้องแยกให้ออกคือ เวลาเกมมีปัญหา ส่วนใหญ่เราแก้แค่ **rule ข้อเดียว** ได้ โดยไม่ต้องทิ้งทั้ง mechanic

ตัวอย่างใน [[candle-cave]]: component คือแถบเทียน 10 ช่องบนกระดาษ rule มีสองข้อคือ "เข้าห้องใหม่ลบ 1 ขีด" และ "เทียนหมดตอนยังอยู่ในถ้ำ = แพ้" สอง rule นี้รวมกันกลายเป็น mechanic แบบ **countdown timer** คือทรัพยากรที่เป็นทั้งนาฬิกาและเงื่อนไขแพ้ ถ้าเกมจบเร็วเกินไป ให้แก้ rule (เปลี่ยนเทียนเริ่มต้นจาก 10 เป็น 12) ไม่ต้องทิ้ง mechanic ทั้งตัว

## แบบฝึก
1. เลือกเกมที่รู้จักดีมาหนึ่งเกม เช่น UNO แล้วทำตาราง 3 คอลัมน์ในส่วน "ความเข้าใจของผม" คือ component / rule (อย่างน้อย 5 ข้อ) / mechanic (อย่างน้อย 2 อย่าง พร้อมบอกว่าประกอบจาก rule ข้อไหน)
2. ใน `dice-duel-rules-v1.md` เขียนหัวข้อ Components กับ Mechanics ให้ครบ ทุก mechanic ต้องชี้ได้ว่ามาจาก rule ข้อไหน
3. ตอนทำ v2 ให้ระบุในหัวข้อ "เปลี่ยนอะไรจากเวอร์ชันก่อน" ว่าแต่ละการเปลี่ยนแก้ที่ระดับ rule หรือระดับ mechanic
