# Kinds of Fun (ความสนุกแต่ละแบบ และ MDA)

## คืออะไร
คำว่า "สนุก" กว้างเกินกว่าจะใช้ออกแบบได้ **MDA framework** (Hunicke, LeBlanc, Zubek, 2004) แบ่งเกมออกเป็นสามชั้น **Mechanics** คือกติกาและชิ้นส่วน (ดู [[mechanic-vs-rule]]) **Dynamics** คือพฤติกรรมที่เกิดขึ้นจริงเมื่อ mechanics เจอกับผู้เล่น **Aesthetics** คือความรู้สึกที่ผู้เล่นได้รับ ผู้ออกแบบคุมได้ตรงๆ แค่ mechanics ส่วนความรู้สึกเกิดขึ้นทางอ้อมผ่าน dynamics นี่คือเหตุผลที่ต้อง [[playtesting]] เสมอ บทความเดียวกันแบ่งความสนุกไว้ 8 แบบ

| แบบ | ความหมาย |
|---|---|
| Sensation | ความรู้สึกทางกาย เช่น เสียงลูกเต๋ากลิ้งบนโต๊ะ |
| Fantasy | ได้เป็นใครสักคนในโลกสมมุติ |
| Narrative | เรื่องราวที่ค่อยๆ คลี่ออก |
| Challenge | อุปสรรคที่ต้องเอาชนะ |
| Fellowship | การได้เล่นกับคนอื่น |
| Discovery | การสำรวจสิ่งที่ยังไม่รู้ |
| Expression | ได้แสดงตัวตนหรือสไตล์ของตัวเอง |
| Submission | เป็นงานอดิเรกที่ผ่อนคลาย ไม่ต้องคิดมาก |

ตัวอย่างใน [[candle-cave]]: aesthetics ที่ตั้งใจคือ **Challenge + Discovery** (บวก Fantasy ของถ้ำมืด) dynamics ที่ต้องเกิดคือ "ลังเลก่อนเข้าห้องถัดไป" และ mechanics ที่สร้าง dynamics นั้นคือเทียนกับตารางสุ่มห้อง ถ้า playtest แล้วไม่มีใครลังเลเลย แปลว่า dynamics ไม่เกิด ความรู้สึกที่ตั้งใจไว้ก็ไม่เกิดตาม

## แบบฝึก
1. ก่อนเขียน Dice Duel v1 ให้เขียน 1 ประโยคไว้บนสุดของไฟล์กติกา: **"ผมอยากให้ผู้เล่นรู้สึก ___"** โดยเลือก aesthetics หลักไม่เกิน 2 แบบ
2. เขียนต่อว่าคาดว่าจะเกิด **dynamics** อะไร ที่ทำให้ผู้เล่นรู้สึกแบบนั้น
3. หลังเล่นกับคนอื่น ให้ถามเขาว่า "ช่วงไหนสนุกที่สุด ช่วงไหนน่าเบื่อที่สุด" ต้องถามหลังจบเกม ไม่ใช่ระหว่างเล่น แล้วบันทึกเทียบกับที่ตั้งใจไว้ในหัวข้อ "ความรู้สึก เทียบกับที่ตั้งใจ" ของ log
